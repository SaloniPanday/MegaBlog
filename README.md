# 🚀 MegaBlog – Blogging Platform

MegaBlog is a responsive blogging application built using React.js and Appwrite. Users can create, edit, delete, and publish blog posts easily.

## 🌐 Live Demo
[Visit MegaBlog](https://mega-blog-2tpy.vercel.app/)

## ✨ Features
- User Authentication
- Create, Edit & Delete Blogs
- Rich Text Editor (TinyMCE)
- Image Upload using Appwrite
- Responsive UI

## 🛠️ Tech Stack
- React.js
- JavaScript
- Tailwind CSS
- Appwrite
- TinyMCE
- Vite
